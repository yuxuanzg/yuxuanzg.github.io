为什么要做学术主页

这是示例文章。学术主页是展示个人研究方向、教育经历、项目与笔记的窗口， 也方便与同行交流。本页面演示了一篇文章应有的排版效果。

写下你的初衷：例如「希望把学习过程沉淀下来，同时让更多人了解我的研究兴趣」。

接下来要做什么

  • 替换头像与个人信息（编辑 index.html）
  • 补充真实的教育经历与项目
  • 把示例文章替换成自己的学习笔记
  • 推送到 GitHub 并开启 GitHub Pages

一点小技巧

正文中可以使用 <h2> 分节、<blockquote> 引用、 <ul> 列表等 HTML 标签来组织内容，样式会自动生效。
